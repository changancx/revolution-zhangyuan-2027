# 革命：张院 2027

一场校园版宪政危机。**周正 × 董事会**，十二天。
双击 `index.html` 就能玩：无服务器、无依赖、字体已打包在本地。

## 你是

**周正**。校董会昨夜发出通知，宣布学生自治委员会解散；今早桃园门口换了保安。
楼里还有两百多人，楼外是操场上的学生，楼对面是董事会和保安大队。

## 每天四件事

| 做什么 | 怎么算 |
| --- | --- |
| **两道命令** | 地图上点地点，再点行动。**每个选项一天只能用一次**，用完就灰。 |
| **一道决议** | 以桃园名义发布正式文件，一日一道。 |
| **媒体** | 舆论页拉拢校媒（一天一家），拉过来后每天发一条「发声」，花舆论点。 |
| **一个事件** | 早间弹出，三选一。 |

底部常驻入口与左上角导航同款：**菜单（ESC）· 桃园（TAB）· 舆论（M）· 决议 · 结束回合（ENTER）**。

## 地点支持度（照原版 vs 数值）

每个地点都有「支持桃园」的百分比，能在图上看到进度条，拉拢方式就是去那个地点做事：

| 地点 | 开局支持桃园 | 出处 |
| --- | --- | --- |
| 桃园 | 100% | 白宫 |
| 大操场 | 75% | 斯摩棱斯克广场 |
| 保卫处 | 45% | 总参谋部 |
| 保安大队 | 35% | 国防部 |
| 博学楼 | 22% | 市政府 |
| 融媒体中心 | 15% | 奥斯坦金诺 |
| 学生会 | 12% | 内务部 |
| 董事会 | 4% | 克里姆林宫 |

开局融媒体中心、博学楼、学生会都站在董事会一边（< 50%）。支持度越过 50，那个地点就倒向桃园。
**保安支持 = 保安大队与保卫处的平均值**，是四根指标之一。

## 四根指标 + 一条暗线

- **决心**：归零 → 桃园散了。决心收益乘「有效席位」。
- **激进**：到 95 → 操场出事。
- **全校支持**：决定成败，也决定强攻时能凑多少人。
- **保安支持**：保安大队与保卫处站哪边，越高越好；85 以上会倒戈。

### 董事会怀疑（时钟）

开局 15%。你每做一件事都涨：**激进涨最快，全校支持次之，谈判能压下去**；每天早上时间本身也让它 +2。
**40%** 盯着你们 · **60%** 准备清场（「距强攻」亮出天数）· **80%** 清场 · 第 12 天必定清场。

## 媒体（照原版 Эфир）

15 家校媒，分三类阵营：**支持桃园 / 中立 / 支持董事会**（另有校电视台、桃园楼内广播）。

- **舆论** 是资源，每晚由你手里媒体的「覆盖」数加总进账；发声要花它。
- **六种拉拢方式**（一天只能对一家出手一次）：编辑部里的自己人（需对应派系忠诚）/ 独家（花一道命令）/ 泄密（花舆论、加怀疑）/ 保护决议（花今天的决议）/ 施压（60% 概率，失败全校支持 −3）/ 创办者权利（花命令、需有效席位）。
- 拉过来之后，那家每天能发一条「发声」，效果各异。
- 融媒体中心（锁）只能在地图上夺取：支持度 ≥ 50 即归你，每晚舆论 +6。

## 派系（桃园里）· 照原版 8 个

楼内 6 个派别 + 楼外 2 支人。忠诚分五档：**敌对 / 不可靠 / 动摇 / 忠诚 / 死忠**。

| 派系 | 人数 | 楼层 | 开局忠诚 | 每晚 |
| --- | --- | --- | --- | --- |
| 张院人 | 78 | 3F | 死忠 | 决心 +1 |
| 母校 | 61 | 3F | 忠诚 | 支持 +1 |
| 学生联盟 | 44 | 2F | 动摇 | 在楼人数 +4 |
| 教工代表 | 34 | 2F | 动摇 | 支持 +1 |
| 观望派 | 22 | 1F | 不可靠 | 添乱：在楼人数 −4 |
| 宿管会 | 29 | B1 | 不可靠 | 添乱：决心 −2 |
| 学生力量 | 96 | 楼外 | 忠诚 | 支持 +2 |
| 军训教官 | 26 | 楼外 | 忠诚 | 保安支持 +2 |

忠诚 **≥ 70** 每晚给加成，**≤ 30** 每晚添乱，中间只出一半力。
忠诚度 × 人数 = **有效席位**（地图上桃园的进度条就是这个）。

楼外的两支可以「请进楼」——进楼后算进在楼人数，楼层图会多出一行。

## 事件 · 照原版

- 每天一个，开局三天是固定的（1400 号通知 → 跳闸 → 台阶上的人），之后按阶段随机。
- 每个事件有**钟点**（如 `20:40`）和一句**引语**。
- 有些选项**有门槛**：舆论不够、有效席位不够、决心不够时，选项会变灰并显示缺什么。
- 共 44 条事件，覆盖对峙 / 僵持 / 强攻三个阶段。

## 八个结局

联合声明 · 点名 · 岗亭上的旗 · 东南角 · 不足 · 三方调停 · 灯全亮着 · 桃园。
