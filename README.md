一场校园版宪政危机。**周正 × 董事会**，二十天（照原版 9/14 → 10/4）。
双击 `index.html` 就能玩：无服务器、无依赖、字体已打包在本地。

## 地点支持度（照原版 vs 数值）

每个地点都有「支持桃园」的百分比，能在图上看到进度条，拉拢方式就是去那个地点做事：

| 地点 | 开局支持桃园 | 出处 |
| --- | --- | --- |
| 桃园 | 100% | 白宫 |
| 大操场 | 75% | 斯摩棱斯克广场 |
| 保卫处 | 45% | 总参谋部 |
| 保安大队 | 35% | 国防部 |
| 博学楼 | 22% | 市政府 |
| 融媒体中心 | 15% | 奥斯坦金诺 |
| 学生会 | 12% | 内务部 |
| 董事会 | 4% | 克里姆林宫 |

开局融媒体中心、博学楼、学生会都站在董事会一边（< 50%）。支持度越过 50，那个地点就倒向桃园。
**保安支持 = 保安大队与保卫处的平均值**，是四根指标之一。

## 四根指标 + 一条暗线

- **决心**：归零 → 桃园散了。决心收益乘「有效席位」。
- **激进**：到 95 → 操场出事。
- **全校支持**：决定成败，也决定强攻时能凑多少人。
- **保安支持**：保安大队与保卫处站哪边，越高越好；85 以上会倒戈。

### 董事会怀疑（时钟，照原版 pr 0–100）

开局 **0**，满 **100** 就清场。每晚按公式涨（基数 7，最低 2）：

`
+2 如果保卫处支持 ≥65      +1 如果学生会支持 ≤10
+1 如果保安大队支持 ≥65    +1 如果全校支持 ≤25
-1 如果全校支持 ≥65        +1 如果激进 ≥60，≥80 再 +1
-1 如果在楼人数 ≥200
`

**45%** 盯着你们 · **70%** 开始准备清场（这时「距强攻」才显示还要几天）· **90%** 明早动手 · **100%** 决定清场 → **再倒数 3 天** 才真打 · 第 20 天必定清场。
所以拉拢保卫处/保安大队、把支持抬起来、把激进压下去，是真的能让它慢下来的。

## 强攻（照原版：按小时守）

从 **07:00 守到 18:00**，一小时一回合，共 11 小时。

- **守备人数**由全校支持、有效席位、保安支持凑出来（5–30 人），开打前要分到 **正门 / 东侧楼梯 / 广播室**。
- 每小时有两处被压上，来犯从 3 人涨到 8 人左右；守卫人数不少于对方就守住，否则**该处被冲破：决心 −7、支持 −4、舆论 −6**，该处守卫全损。
- 每小时可下**一道指令**：
  - **固守** 最弱一处 +1
  - **反击** 来犯 −1，决心 −2，伤 1 人
  - **撤回内圈** 外围各撤 1 人到底楼
  - **呼叫支援** 舆论 ≥30 时补 2 人，花 8 点舆论
- 三处全破或决心归零 → 失守；撑到 18:00 → 守住。

结局分三层（照原版 win / neutral / lose）：

| 局面 | 结局 |
| --- | --- |
| 守住，舆论 ≥45 | **灯全亮着**（或三方调停） |
| 守住，但舆论塌了 | **燃烧的楼**（守住了楼，没人承认） |
| 失守，但舆论 ≥50 | **校董会的惨胜**（楼拿下了，权力没拿住） |
| 失守 | **桃园** |
## 媒体（照原版 Эфир）

15 家校媒，分三类阵营：**支持桃园 / 中立 / 支持董事会**（另有校电视台、桃园楼内广播）。

- **舆论** 是资源，每晚由你手里媒体的「覆盖」数加总进账；发声要花它。
- **六种拉拢方式**（一天只能对一家出手一次）：编辑部里的自己人（需对应派系忠诚）/ 独家（花一道命令）/ 泄密（花舆论、加怀疑）/ 保护决议（花今天的决议）/ 施压（60% 概率，失败全校支持 −3）/ 创办者权利（花命令、需有效席位）。
- 拉过来之后，那家每天能发一条「发声」，效果各异。
- 融媒体中心（锁）只能在地图上夺取：支持度 ≥ 50 即归你，每晚舆论 +6。

## 装成手机 App（PWA）

这是纯静态页面，**零外部请求**，所以可以直接装到桌面：

**安卓（Chrome / Edge）**
1. 打开在线地址 → 右上角 ⋮ → **安装应用**（或「添加到主屏幕」）
2. 之后点图标就是全屏横屏、没有地址栏，断网也能玩

**iPhone / iPad（Safari）**
1. 打开在线地址 → 底部 **分享** → **添加到主屏幕**
2. 从主屏幕图标启动才是全屏（在 Safari 标签页里会有地址栏）

**实现**：`manifest.json`（全屏、强制横屏、主题色）+ `sw.js`（预缓存 14 个文件，断网可用）+ 像素图标（`tools/make-icons.js` 用 Node 手写 PNG 生成，不依赖任何图形库）。
发新版时把 `sw.js` 里的 `CACHE = 'zhangyuan-v1'` 版本号 +1，手机上会自动换新。

## 声音

全部用 WebAudio 现场合成，**不带任何音频文件**（仓库不增加体积，也不牵扯版权）：

- **音效**：点击、确认、失败、盖章、翻报纸、打字、人群、电击、警报、胜负。
- **背景乐**：两段程序生成的循环——平时是慢速的暗色和弦，进入强攻自动切成急促的低音脉冲。
- **开关**：封面菜单「声音：开/关」，或随时按 `S`；状态存在 localStorage。

## 改内容'

`js/data.js` 六张表：`FR` `LOC`（含 `vs`）`ACT` `LAW` `EV` `OUTLETS`/`OUT_WAYS`/`OUT_X`。
